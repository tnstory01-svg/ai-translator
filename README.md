# AI Translator

복수전공(언어/번역 + IT) 학습 경험을 살려 만든 AI 기반 번역 도구입니다.

## 프로젝트 목표

- 단순 기계 번역을 넘어, 문맥과 어조를 고려한 자연스러운 번역 결과 제공
- 비전공자가 AI 페어 코딩 도구를 활용해 실제 동작하는 서비스를 구현하는 학습 과정 기록
- 프롬프트 설계, API 연동, 보안(키 관리) 등 실무 감각 익히기

## 기술 스택 (예정)

- **Language**: Python
- **AI**: OpenAI / Anthropic API
- **UI**: Streamlit 또는 간단한 웹 프론트
- **환경 관리**: `.env` (API 키 분리), `requirements.txt`

## 학습 포인트

- AI 코딩 보조 도구를 활용한 개발 흐름 체득
- API 키 노출 방지 등 기본 보안 고려사항 적용
- Git/GitHub을 통한 형상 관리 습관 형성

## 동기

언어 전공으로 쌓아온 "좋은 번역이란 무엇인가"에 대한 감각을, IT 학습으로 얻은 도구로 직접 구현해보고자 시작한 프로젝트입니다.
